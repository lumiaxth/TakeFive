# 歇会儿 - 健康上网助手

一款基于 Manifest V3 的浏览器插件（Chrome / Edge），统计每日各网站的使用时长，为网站设置时间限制、提醒与屏蔽，并用番茄钟帮助你专注、及时休息。

## 功能

- **时长统计**：自动记录每个注册级域名今日累计使用时长（如 `mail.google.com`、`www.google.com` 统一计为 `google.com`），按天归档并保留最近 7 天。
- **时间限制**：为单个域名设置每日限额与提醒阈值。接近限额时推送桌面通知，达到限额后禁止继续访问（包括已打开的页面，会被重定向到阻断页）。
- **访问屏蔽**：将域名加入黑名单后，访问即被重定向到阻断页，且不受"休息"暂停影响；新增黑名单/限额会立即作用于已打开的标签页。
- **暂停机制**：手动开关——暂停计时后，插件图标显示红色底纹 + 白色横杠角标，期间不计时、不限额（黑名单除外），随时可恢复。
- **图标角标**：插件图标实时显示时长（格式 `h:mm`，10 小时以上显示紧凑 `10h`）。自动模式下，普通网页显示当前域名时长，空白/系统标签页显示今日总时长，番茄钟运行时显示剩余时长；也可在设置中选择固定显示类型。
- **深色模式**：设置「外观」模块可选**跟随系统 / 浅色 / 深色**主题，界面配色参考 Edge 深色风格。
- **浮动倒计时**：网页侧边（含设置页、数据页、阻断页）实时显示番茄钟（🍅/☕）与站点剩余（⏳）倒计时，支持开关、6 种位置与 3 档大小。
- **浮动时钟**：复用浮窗样式显示当前时间（HH:MM），可单独开启/关闭。
- **连续使用提醒**：连续使用浏览器达到设定时长（默认 45 分钟）时，桌面通知 + 页面横幅提醒；离开浏览器超过 2 分钟视为中断，重新计时。
- **番茄钟**：设置页「启用番茄钟」控制功能开关（默认开启）；开启后弹窗底部显示番茄钟模块，点击「开始专注」开始倒计时（默认 25 / 5 分钟专注/休息周期），显示精确到秒。番茄钟按**自然时间**倒计时（离开/失焦/暂停期间仍持续推进）；休息结束若你已离开则停止本轮并通知；浏览器关闭自动停止，下次打开时通知。专注阶段将禁止访问白名单以外的网页（仅当前活动标签页被拦截）；白名单支持手动添加或一键导入当前已打开的网页。
- **提醒形式**：桌面通知 + 页面顶部横幅（内容脚本实现，自动隐藏）。
- **多语言**：根据浏览器系统语言自动切换中文 / English。

## 安装

### Chrome（CRX 安装）
1. 打开 [GitHub Releases](https://github.com/lumiaxth/TakeFive/releases)，下载最新的 `.crx` 文件。
2. 打开 Chrome 扩展管理页面：`chrome://extensions`。
3. 右上角开启「开发者模式」。
4. 将下载的 `.crx` 文件**拖拽**到扩展管理页面，按提示完成安装。
   > 若 Chrome 提示“无法添加来自此网站的应用、扩展程序或用户脚本”，请改用下方的“开发模式加载”，或将 CRX 解压后使用“加载已解压的扩展程序”。
5. 安装完成后，工具栏出现图标即可使用。

### 开发模式加载
1. 打开浏览器扩展管理页：Chrome 访问 `chrome://extensions`，Edge 访问 `edge://extensions`。
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本仓库目录（含 `manifest.json` 的根目录）。
4. 工具栏出现图标后即可使用。

> 每次代码更新后，回到扩展管理页点击「重新加载」即可生效。

## 使用方法

- **查看统计**：点击工具栏图标，弹窗展示今日总时长与各域名使用时长，每行可加入黑名单、为未设限额的域名设置限额；番茄钟开启后，弹窗底部显示番茄钟模块，可点击「开始专注」开始 / 「结束专注」停止。右上角图标可进入设置页或数据页。
- **数据页**：今日总时长与域名明细、近 7 天每日总时长柱状图，点击柱子查看当天总时长与时长前五域名；支持重置今日/清空全部数据。
- **设置限制与黑名单**：右键图标「选项」（或设置页入口），管理限额规则、黑名单、图标角标显示类型、连续使用提醒、番茄钟（时长与白名单，白名单可一键导入当前打开的网页）。
- **被阻断时**：达到限额的域名会跳转到阻断页，可点击「暂停记录并继续」暂停统计后继续；黑名单与番茄钟（专注阶段）的阻断页不提供放行入口，番茄钟白名单外的阻断需在弹窗暂停或调整白名单。

## 项目结构

```
healthy_explorer/
├── manifest.json          # MV3 配置（权限、入口、默认语言、内容脚本）
├── background.js          # Service Worker：计时、限额/提醒/阻断、暂停、连续使用提醒、番茄钟、倒计时/时钟推送
├── content/
│   ├── banner.js          # 页面顶部横幅内容脚本（Shadow DOM 隔离）
│   └── countdown.js       # 浮动倒计时/时钟内容脚本（Shadow DOM，注入网页与插件页）
├── popup/                 # 工具栏弹窗：今日概览 + 快捷操作 + 番茄钟开关
├── options/               # 设置页：外观（主题/角标）/ 倒计时 / 限额 / 黑名单 / 提醒 / 番茄钟
├── dashboard/             # 数据页（仪表盘）：今日概览 + 近 7 天柱状图 + 详情
├── blocked/               # 阻断落地页
├── shared/
│   ├── storage.js         # 数据读写、每日重置、限额判断
│   ├── hostname.js        # 注册级域名解析（基于 tldts）
│   ├── i18n.js            # 界面多语言辅助
│   ├── theme.js           # 主题（跟随系统/浅色/深色）解析与应用
│   └── tldts.min.js       # 公共后缀列表解析库（第三方，UMD 单文件）
├── _locales/              # 多语言文案（en / zh_CN）
└── icons/                 # 插件图标
```

## 权限说明

| 权限 | 用途 |
|---|---|
| `tabs` | 读取活动标签页 URL，识别当前域名 |
| `storage` | 保存统计数据与设置（仅本地） |
| `alarms` | 定时提交计时数据，保证准确 |
| `notifications` | 限额接近/达成的桌面提醒 |
| `webNavigation` | 监听导航并重定向到阻断页 |
| `windows` | 感知窗口聚焦，仅在前台时计时 |
| `idle` | 检测锁屏/睡眠，自动停止计时；判定番茄钟「离开」状态 |
| `scripting` | 动态注入浮动倒计时/时钟内容脚本到已打开的网页 |
| `host_permissions: <all_urls>` | 允许 `webNavigation` 观察到任意站点的导航（用于屏蔽） |

## 计时说明

- 仅当 **浏览器窗口在前台 + 目标标签页为活动页 + 未暂停** 时计时，不依赖鼠标键盘操作。
- 数据每 30 秒落盘一次；Service Worker 被系统回收后重启，会从存储锚点续算，避免漏计。
- **电脑锁屏或睡眠时不计时**：通过系统 idle 状态检测锁屏，并拒绝跨度超过 3 分钟的单次提交（睡眠/挂起期间不计入）；仅锁屏/睡眠停止，熄屏但电脑仍唤醒时继续按前台停留计时。
- 浏览器关闭超过 2 分钟视为离开，不计入时长。
- 「连续使用提醒」随前台计时推进；离开浏览器超过 2 分钟会重置连续使用计时。**番茄钟按自然时间倒计时**（离开/失焦/暂停期间仍推进）。
- 所有数据存储在 `chrome.storage.local`，卸载扩展即清除。
